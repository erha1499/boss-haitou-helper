# BOSS 海投助手

在 [BOSS 直聘](https://www.zhipin.com/) 职位页上按你的规则筛选岗位，并自动发起沟通的浏览器用户脚本。

## 功能

- **求职向导**：选身份、方向和技术栈，一键生成筛选规则
- **多层筛选**：岗位类型（实习 / 校招 / 社招及年限）、职位名、工作地、公司、薪资、职位描述、招聘者
- **实时预览**：改规则时用当前页岗位试跑，显示会收集多少个、哪个词误伤了
- **投递状态**：面板和网页标签标题显示进度，日志可只看已投递或跳过的记录，写明每个岗位为什么被跳过
- **补投**：被细筛跳过的岗位会列在「可补投」里，误跳过的勾选后跳过细筛重新投
- **安全停止**：达到今日目标或 BOSS 的 150 次上限自动停止；页面结构变了也会自检停下
- **投递历史**：按日期查看投过的公司和岗位，可一键拉黑公司
- **配置分享**：规则可复制成文本发给别人导入

## 安装

1. 安装脚本管理器：[脚本猫 ScriptCat](https://scriptcat.org/) 或 [Tampermonkey](https://www.tampermonkey.net/)（Chrome、Edge、Firefox 均可）
2. 点击安装：[boss-haitou-helper.user.js](https://github.com/erha1499/boss-haitou-helper/raw/main/boss-haitou-helper.user.js)

脚本会自动更新。需要较新版本的 Chrome 或 Edge。

## 快速开始

1. 登录 BOSS 直聘，进入顶部导航的「职位」页
2. 在 BOSS 页面上**只选城市**，不要开 BOSS 自带的求职类型、经验等筛选。很多岗位的标签没填准，开了会漏掉大量岗位，交给脚本的规则来筛
3. 打开脚本面板的「筛选设置」，用「求职向导」生成规则，或导入下面的常用岗位配置
4. 填写「今日目标」，点「开始投递」。投递时让职位页保持在前台，后台标签页会被浏览器限速

中途停止后再开始会接着往下投；改了规则后再开始，当前页的岗位会按新规则重新判断。

细筛跳过的岗位（命中排除词、岗位类型不符、招聘者不符、详情加载超时等）会记在日志上方的「可补投」里，按天保存。勾选误跳过的点「补投选中」，脚本会跳过细筛直接沟通，其余和正常投递一样：计入今日次数，投满今日目标就不能再补投。刷新或换了搜索后不在当前页的岗位，可以点「打开」手动沟通。

## 常用岗位配置

在「筛选设置」底部点「导入配置」，粘贴配置文件的全部内容即可（在 GitHub 上打开文件，点右上角的复制按钮）。导入前会预览改动，导入后可以撤销。

| 配置 | 投哪些岗位 |
|---|---|

| [前端 · 实习 / 校招](configs/frontend-intern-campus.json) | 前端实习、校招岗 |
| [AI 应用 / Agent 开发 · 实习 / 校招](configs/ai-agent-intern-campus.json) | 大模型应用、Agent、AIGC 等岗位，可与后端重叠 |
| [算法 / 大模型 · 实习](configs/algorithm-intern.json) | 机器学习、CV、NLP、推荐搜索、大模型训练等实习 |
| [测试开发 · 校招](configs/testing-campus.json) | 测试、测开校招岗 |
| [数据开发 · 校招](configs/data-campus.json) | 数据开发、大数据、数仓校招岗 |
| [Go 后端 · 社招 3 年以内](configs/go-backend-social-under-3y.json) | 要求 3 年以内经验的后端 / Go 岗，月薪 15K 起 |
| [Java 后端 · 社招 5 年以内](configs/java-backend-social-under-5y.json) | 要求 5 年以内经验的后端 / Java 岗，月薪 20K 起 |

每套配置都会：排除没选的技术方向和销售、客服、运营等非技术岗；只投 3 天内活跃的招聘者；跳过描述里写了外包、驻场、劳务派遣的岗位。工作地、排除公司留空，导入后按需补上。

## 筛选规则

| 规则 | 说明 |
|---|---|
| 岗位类型 | 实习 / 校招·应届 / 社招，社招可限定年限。没标类型的岗位照常收集，打开详情后按描述再判断 |
| 职位名 | 必须包含 / 包含任一 / 排除 |
| 工作地、排除公司 | 命中任一即生效，留空不限 |
| 薪资 | 最低、最高月薪（K），日薪按每月 24 天折算，可选是否包含「面议」 |
| 职位描述 | 打开详情后判断：排除 / 必须包含 / 包含任一 |
| 招聘者 | 按活跃状态过滤，或只投指定职位的招聘者（如 HR） |

猎头岗位和已经沟通过的岗位会自动跳过。

**关键词写法**：不区分大小写；`|` 分隔多种写法（`前端|客户端`）；英文按整词匹配（`java` 不匹配 JavaScript）；末尾加 `*` 按前缀匹配（`spring*` 匹配 SpringBoot）；支持正则（`不.{0,3}实习`）。

<details>
<summary>岗位类型是怎么判断的</summary>

BOSS 的经验标签没有“实习”，所以脚本综合三处信息判断：

1. **标签**：`在校/应届` → 校招，`经验不限` → 经验不限，`1-3年` 等 → 社招对应年限，`4天/周`、`6个月` → 实习
2. **职位名和薪资**：含“实习 / intern”或按天计薪 → 实习；含“校招、应届、管培、2027届、秋招” → 校招
3. **职位描述**：“3年以上工作经验”“3+ years of experience” → 社招；“实习期、可转正、每周至少4天” → 实习；“应届毕业生、2027届” → 校招

写明年限要求的一律按社招处理，取最高的年限。下面这些不算：

- 加分项：“有2年以上银行项目经验者优先”“… is a plus”
- 候选人的经历或否定说法：“1年以上实习经验”“不接受实习生”“不要求3年经验”
- 正式岗的“试用期表现优秀可转正”、高级岗的“指导实习生”、社招常写的“统招本科毕业生”

标签、职位名和描述都看不出类型的（包括只写了“经验不限”的），不管选了哪些类型都照常投，不会因为招聘方没填标签就被过滤。被跳过的岗位，日志会写明依据。

</details>

## 注意事项

- 配置、投递次数和历史都存在浏览器本地，不会上传。清除 zhipin.com 的网站数据会一并清空
- 自动投递有被平台限制的风险，请合理设置每日目标
- BOSS 改版可能导致脚本失效，日志里出现「页面检查异常」时欢迎到 [Issues](https://github.com/erha1499/boss-haitou-helper/issues) 反馈
- 仅供学习交流，请勿用于商业用途

## 开发

源码在 `src/`，用 Rollup 打包成根目录的 `boss-haitou-helper.user.js`，构建结果需要提交。需要 Node.js 22 以上。

```bash
npm install
npm run build   # 生成用户脚本和 configs/ 下的常用岗位配置
npm test        # 运行测试，并检查构建结果是否最新
```

- `src/rules/`：筛选规则，不依赖页面，单元测试覆盖
- `src/boss/selectors.js`：BOSS 页面选择器，BOSS 改版后先改这里
- `scripts/presets.js`：常用岗位配置的定义
- `test/delivery-flow.test.js`：在模拟的职位页上跑完整投递流程

发版时改 `src/meta.js` 里的 `@version`。
